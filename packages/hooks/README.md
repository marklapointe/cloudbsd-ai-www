# @cloudbsd/hooks

Shared React hooks for CloudBSD and RevyTech projects.

## Install

```bash
npm install @cloudbsd/hooks
```

## Hooks

- `useTheme` - Dark/light mode theme management
- `useLanguage` - Language selection and i18n management
- `useAuth` - Authentication state (localStorage)
- `useNotifications` - Notifications state management

## Peer Dependencies

```json
{
  "react": ">=18.0.0"
}
```
