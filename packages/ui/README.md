# @cloudbsd/ui

Shared UI primitives for CloudBSD and RevyTech projects.

## Install

```bash
npm install @cloudbsd/ui
```

## Components

- `LanguageSelector` - Language dropdown with mobile/full support
- `ThemeToggle` - Dark/light mode toggle button
- `Button` - Button with variants
- `Badge` - Status badge component
- `Card` - Card container
- `GlassCard` - Glass morphism card

## Peer Dependencies

```json
{
  "react": ">=18.0.0",
  "react-i18next": ">=14.0.0",
  "tailwindcss": ">=3.4.0"
}
```
