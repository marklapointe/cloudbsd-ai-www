# @cloudbsd/ui-admin

Admin-specific UI components for CloudBSD admin panel.

## Install

```bash
npm install @cloudbsd/ui-admin
```

## Components

- `ResourceList` - Paginated, sortable, searchable resource list
- `ResourceModal` - Create/edit form modal
- `ConfirmationModal` - Confirmation dialog
- `ConsoleModal` - VM/Container console modal
- `CustomPageSizeModal` - Custom pagination size modal
